# FFmpeg C++ 极简播放器学习项目 

这是一个基于 FFmpeg 和 SDL3，由现代 C++ 编写的跨平台多媒体播放器学习项目。本项目从零起步，尝试构建一个播放器最核心的底层数据流转过程，包含基础的多线程模型和音视频同步机制。

作为初学者的练手产物，代码中包含了大量踩坑复盘和学习过程中的中文注释，希望能为同样在学习音视频底层的萌新朋友提供一份浅显易懂的参考资料。

## 🌟 包含的特性探索

*   **C++ 基础封装**：尝试将 `Demuxer`, `Decoder`, `Renderer` 等模块进行简单的面向对象抽象，理清各个核心模块的职责。
*   **基础音视频同步**：
    *   练习以音频为主时钟 (Master Clock)。
    *   探索并加入了**系统时间跨帧平滑差值 (Interpolation)** 算法，缓解播放画面卡顿现象。
*   **硬件解码初探**：
    *   尝试调用相关 API 获取 GPU 加速配置 (如 NVDEC 等)。
    *   跑通显存 (VRAM) 数据拷贝回物理内存 (RAM) 的基础流程。
*   **音频滤镜学习**：
    *   接入 `atempo` 滤镜，支持基本的倍速同步播放。
*   **进度控制 (Seek 机制)**：
    *   学习并引入简易的时钟序列检查（**Epoch / 哨兵包机制**），尝试处理多线程安全下的队列冲刷防暴走问题。
*   **色彩空间转换**：
    *   遇到非标准像素格式时，加入 `SwsScale` 回退运算，输出 SDL 支持的常见渲染格式。

## 🎮 基本操作

可以在控制台传入参数启动本程序：

| 操作 | 功能描述 |
| :--- | :--- |
| `鼠标点击` | 进度条绝对拖拽跳转 |
| `Left / Right` | 步进快进/快退 (加入简易防抖机制) |
| `Up / Down` | 调整音量 |
| `[ / ]` | 减速 / 加快全局播放倍数 (0.5x - 2.0x) |
| `J` | 测试用键盘调节音视频时间轴误差 |

终端启动示例：
```bash
# 启动播放器并传递文件路径
./ffmpeg_learn03 /path/to/your/movie.mp4
```

## 🛠️ 编译与依赖

### 基础环境
*   **C++ 编译器**: 支持 C++11 或更高版本
*   **CMake**: 3.10+
*   **FFmpeg**: 6.x / 7.x 开发库 (libavcodec, libavformat, libavfilter, libswscale 等)
*   **SDL3**: 视频与音频渲染端

### 编译流程 

1. 克隆本项目：
```bash
git clone https://github.com/你的名字/ffmpeg_cpp_player.git
cd ffmpeg_cpp_player
```
2. 基础编译：
```bash
mkdir build && cd build
cmake ..
make -j8
```
成功后在 `build` 目录下可得到 `ffmpeg_learn03` 执行文件。

*注：Windows 用户需要使用 MinGW/Visual Studio，并确保环境变量已正确配置 FFmpeg/SDL3 的动态链接库。*
